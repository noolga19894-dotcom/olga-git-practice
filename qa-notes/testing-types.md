# Testing Types

## Functional Testing
Checks whether the system works according to the requirements.

## Non-Functional Testing
Checks characteristics such as performance, usability and security.

## Positive Testing
Checks that the system works with valid input.

## Negative Testing
Checks how the system behaves with invalid or unexpected input.

## Regression Testing
Checks that existing functionality still works after changes.

## Retesting
Checks that a specific defect has been fixed.
