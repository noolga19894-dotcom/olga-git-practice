Bug Report

1. Bug ID-identifier of the defect
2. Title-short description of the bug
3. Environment-device, OS, browser, application version
4. Preconditions-conditions before reproducing the bug
5. Steps to Reproduce-steps to reproduce the bug
6. Expected Result-what should happen
7. Actual Result-what actually happens
8. Severity-how serious the bug is
9. Priority-how urgently the bug should be fixed
10. Attachments-screenshots, videos, logs
11. Additional Information-other useful details
